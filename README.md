## Proyek

- **Portofolio pribadi**
  Satu halaman dengan tata letak editorial, lanyard 3D berfisika, dan navigasi radial.
  Three.js, GSAP, Lenis, Tailwind CSS. [Kunjungi](https://GANTI-DENGAN-URL-PORTOFOLIO)

- **Toko online audiophile**
  Antarmuka katalog, filter, dan detail produk untuk IEM, DAC, dan aksesori audio.
  Tailwind CSS, GSAP, Vite. Dalam pengerjaan.

- **Plotter pena DIY**
  Braket motor NEMA 17 dan mekanisme pen-lift dengan servo, dirancang lewat kode dan dicetak 3D.
  [Repositori](https://github.com/arrxz/GANTI-NAMA-REPO)
